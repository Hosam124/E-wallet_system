E-Wallet System 💳

This is a Java-based command-line E-Wallet System that simulates a real digital wallet. Users can create accounts, login, deposit, withdraw, transfer money, view account details, and manage their passwords.

The system also includes admin features, transaction history, and input validations to ensure data integrity. It handles errors gracefully and prevents invalid operations like transferring to yourself or overdrawing an account.

Features

Sign-Up: Create an account with username, password, age, and phone number validation.

Login: Secure login with limited invalid attempts.

Deposit & Withdraw: Add or remove money with validation.

Transfer: Send money to another user safely.

Account Details: View username, phone number, age, and balance.

Change Password: Securely update your password.

Logout: Exit the system safely.

Admin Panel: View all accounts, delete or deactivate accounts.

Transaction History: Records all actions like deposits, withdrawals, and transfers.

How to Use

Clone the project.

Open it in IntelliJ IDEA or another Java IDE.

Run Main.java and follow the instructions in the command-line menu.
